XDR Docker Relay

Sends your current Defender XDR sign-in cookie to 127.0.0.1 only, and only for one use. Only paste in a pairing code you just generated yourself, for a container you run and trust on this machine.

Sign in to security.microsoft.com in an Incognito window, with "Allow in Incognito" enabled for this extension (see its Details page). A cookie from your normal, already-signed-in profile is often rejected by Azure AD with "session information is not sufficient for SSO". Once signed in there, this popup can be opened from either window.
